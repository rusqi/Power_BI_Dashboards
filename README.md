# Data Jobs Dashboard with Power BI

An interactive Power BI dashboard exploring data job postings, salaries, and employment trends. This project is part of my journey toward becoming a Data Analyst, where I'm developing practical skills in data transformation, visualization, and business intelligence.

## Project Overview

As I learn data analytics, I want to understand not only how to work with data but also how to turn it into insights that support better decisions.

For this project, I built a Power BI dashboard based on a dataset of data-related job postings from 2024. The dashboard helps job seekers and career changers explore job demand, salary distributions, and other characteristics of the data job market.

The project follows a guided learning approach, allowing me to practice Power BI features and understand how an interactive report can make a large dataset easier to explore.

## Skills Practiced

Through this project, I practiced the following Power BI and data analytics skills.

### 1. Data Transformation with Power Query

- Cleaned and prepared raw job-posting data.
- Handled blank values and adjusted data types.
- Created additional columns to support analysis.
- Prepared the dataset for visualization and reporting.

### 2. Measures and Key Performance Indicators

- Explored measures for metrics such as median yearly salary and job count.
- Used KPI cards to summarize important information.
- Practiced selecting metrics that help users understand the job market quickly.

### 3. Data Visualization

Created and configured several chart types to explore different aspects of the dataset:

- Column and bar charts to compare job counts and salaries.
- Line and area charts to examine trends.
- Map charts to explore the geographic distribution of job postings.
- Tables to present detailed, sortable information.
- Cards to highlight key metrics.

### 4. Interactive Reporting

Practiced making the dashboard more useful through interactive features:

- **Slicers:** Filter the report by job title.
- **Buttons and bookmarks:** Support navigation between report views.
- **Drill-through:** Move from a high-level summary to more detailed information about a selected job title.

### 5. Dashboard Design

- Organized information into a summary page and a detailed page.
- Practiced balancing charts, KPIs, and tables.
- Explored how layout and visual hierarchy affect the readability of a dashboard.

## What I Learned

Working through this project helped me understand how Power BI can be used to transform raw data into an interactive report.

My main learning outcomes were:

- Understanding the basic data preparation workflow with Power Query.
- Practicing measures and KPI creation for reporting.
- Choosing visualizations based on the information they communicate.
- Building interactive reports with slicers, bookmarks, and drill-through.
- Organizing a dashboard around an overview and a more detailed analytical view.
- Recognizing that a useful dashboard should help users answer questions, not simply display charts.
